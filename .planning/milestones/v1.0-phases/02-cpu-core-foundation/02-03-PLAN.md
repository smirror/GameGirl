<threat_model>
Trust boundaries:
- Arithmetic operands may come from ROM immediates or Bus-backed memory.
- CPU flags become downstream control-flow inputs.

STRIDE register:

| threat_id | category | component | disposition | mitigation_plan |
|-----------|----------|-----------|-------------|-----------------|
| CPU-03-T1 | Tampering | flag register updates | mitigated | Centralize flag writes through helpers that mask the lower nibble of `F`. |
| CPU-03-T2 | Denial of Service | arithmetic overflow/underflow | mitigated | Use Rust wrapping arithmetic methods; do not panic on `u8` overflow. |
| CPU-03-T3 | Spoofing | compare instruction state | mitigated | `CP` updates flags without mutating `A`; add tests proving `A` remains unchanged. |

Block on: high severity threats. No high severity threats are expected if arithmetic uses wrapping helpers and flag tests cover edge cases.
</threat_model>
