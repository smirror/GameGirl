<threat_model>
Trust boundaries:
- ROM bytes still enter CPU only through Bus-backed reads.
- Implemented opcodes may write to Bus-controlled memory ranges.

STRIDE register:

| threat_id | category | component | disposition | mitigation_plan |
|-----------|----------|-----------|-------------|-----------------|
| CPU-02-T1 | Tampering | load instruction memory writes | mitigated | Use only `Bus::write8` for `(HL)`, `(BC)`, `(DE)`, high-memory, and absolute writes. |
| CPU-02-T2 | Denial of Service | STOP/HALT placeholders | mitigated | Placeholders return deterministic `StepResult` values and do not loop internally. |
| CPU-02-T3 | Spoofing | unsupported opcode fallback | mitigated | Keep `CpuError::UnsupportedOpcode` for all bytes not explicitly implemented in this plan. |

Block on: high severity threats. No high severity threats are expected if memory writes stay Bus-backed and placeholders do not loop.
</threat_model>

Implement 8-bit immediate loads `0x06 LD B,d8`, `0x0E LD C,d8`, `0x16 LD D,d8`, `0x1E LD E,d8`, `0x26 LD H,d8`, `0x2E LD L,d8`, `0x3E LD A,d8`, each advancing `PC` by 2 and returning 2 machine cycles. Implement `0x36 LD (HL),d8` using `Bus::write8(self.registers.hl(), value)`, advancing `PC` by 2 and returning 3 machine cycles. Implement register load opcodes `0x40..=0x7F` except `0x76`; register-to-register loads return 1 machine cycle, loads reading `(HL)` use `Bus::read8` and return 2 machine cycles, and loads writing `(HL)` use `Bus::write8` and return 2 machine cycles. Implement accumulator memory loads `0x02 LD (BC),A`, `0x12 LD (DE),A`, `0x0A LD A,(BC)`, `0x1A LD A,(DE)`, `0x22 LD (HL+),A`, `0x2A LD A,(HL+)`, `0x32 LD (HL-),A`, `0x3A LD A,(HL-)`, `0xE0 LDH (a8),A`, `0xF0 LDH A,(a8)`, `0xEA LD (a16),A`, and `0xFA LD A,(a16)`. High-memory opcodes use address `0xFF00 + a8`. Absolute opcodes fetch little-endian `a16`. All memory reads/writes must use `Bus`.</action>
