<threat_model>
Trust boundaries:
- CB-prefixed bytes are untrusted ROM data read through Bus.
- Future ROM harnesses will repeatedly call `Cpu::step` and rely on deterministic success/error outcomes.

STRIDE register:

| threat_id | category | component | disposition | mitigation_plan |
|-----------|----------|-----------|-------------|-----------------|
| CPU-05-T1 | Spoofing | CB opcode support claims | mitigated | Return `CpuError::UnsupportedCbOpcode` for all CB subopcodes until operations are deliberately implemented. |
| CPU-05-T2 | Denial of Service | repeated unsupported CB opcodes | mitigated | Return immediately with a structured error and unchanged PC; do not loop internally. |
| CPU-05-T3 | Tampering | cycle reporting contract | mitigated | Add representative cycle tests for implemented opcode families so downstream devices receive stable machine-cycle counts. |

Block on: high severity threats. No high severity threats are expected if unsupported CB behavior remains deterministic and the CPU core performs no host I/O.
</threat_model>
