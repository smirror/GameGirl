<threat_model>
Trust boundaries:
- ROM bytes control branch targets and stack operations.
- Stack writes target Bus-backed memory, currently WRAM/HRAM or any mapped address selected by `SP`.

STRIDE register:

| threat_id | category | component | disposition | mitigation_plan |
|-----------|----------|-----------|-------------|-----------------|
| CPU-04-T1 | Tampering | stack memory | mitigated | Implement push/pop only through `Bus::write8` and `Bus::read8`, with tests checking byte order at stack addresses. |
| CPU-04-T2 | Denial of Service | recursive CALL/RST instruction behavior | accepted-low | CPU step executes exactly one instruction and returns; it does not recursively execute branch targets. |
| CPU-04-T3 | Spoofing | conditional branch flags | mitigated | Tests must set flags explicitly and assert taken/not-taken PC and cycle behavior. |

Block on: high severity threats. No high severity threats are expected because each step remains single-instruction and stack memory remains Bus-owned.
</threat_model>
